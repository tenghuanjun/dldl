## 三、密码加密（AES）

### 3.1 加密流程

```
密码明文 → AES/ECB/PKCS5Padding → Base64 → 加密后密码
```

### 3.2 密钥生成
```java
// EncryptUtil.java:30-48 / AccountLogic.java:1027-1041
private String getEncodeKey() {
    String appKey = ConfigManager.getInstance(context).getAppKey();
    // APP_KEY = "CR.wdPyFoanb6Thv8sJ5rjNDMEeI3@X1"
    int length = appKey.length(); // 32
    if (length < 16) {
        // 不足16位补0
        return appKey.padEnd(16, '0');
    }
    return appKey.substring(0, 16); // 取前16位
    // 结果: "CR.wdPyFoanb6Thv"
}
```

### 3.3 AES 加密实现
```java
// AESUtil.java:16-21
public static byte[] encrypt(String str, String key) throws Exception {
    SecretKeySpec secretKeySpec = new SecretKeySpec(key.getBytes("UTF-8"), "AES");
    Cipher cipher = Cipher.getInstance("AES"); // Java默认 AES/ECB/PKCS5Padding
    cipher.init(1, secretKeySpec); // Cipher.ENCRYPT_MODE
    return cipher.doFinal(str.getBytes("UTF-8"));
}

// AccountLogic.java:1005-1015 - 密码加密入口
private String encryptPwd(String pwd) {
    return Base64.encodeToString(
        AESUtil.encrypt(pwd, getEncodeKey()), 
        2  // Base64.NO_WRAP
    );
}
```

### 3.4 Node.js 等价实现
```javascript
function aesEncrypt(plainText, key) {
  const cipher = crypto.createCipheriv('aes-128-ecb', Buffer.from(key, 'utf8'), null);
  cipher.setAutoPadding(true);
  let encrypted = cipher.update(plainText, 'utf8', 'base64');
  encrypted += cipher.final('base64');
  return encrypted;
}

// AES Key = APP_KEY.substring(0, 16) = "CR.wdPyFoanb6Thv"
// 示例: aesEncrypt("1234561239", "CR.wdPyFoanb6Thv") → "mXjuS+y77Yi7gqhtAjUvKg=="
```

## 四、签名算法（SignV3）

### 4.1 签名流程
```
所有参数 → 按key字母排序 → 拼接"key=value" → 追加APP_KEY → MD5 → 转小写
```

### 4.2 核心实现
```java
// SignV3Interceptor.java:76-91
private static StringBuilder buildString(String appKey, Map<String, String> map) {
    ArrayList<String> keys = new ArrayList(map.keySet());
    Collections.sort(keys);  // 按 key 字母排序
    StringBuilder sb = new StringBuilder();
    for (String key : keys) {
        sb.append(key);
        sb.append('=');
        sb.append(map.get(key));
    }
    sb.append(appKey);  // 最后追加 APP_KEY
    return sb;
}

private static String sign(StringBuilder sb) {
    return MD5Util.Md5(sb.toString()).toLowerCase(Locale.US);
}
```

### 4.3 签名示例

### 4.4 重要细节
- **sign 字段不参与签名**：在签名前先移除 sign 参数
- **空值也参与签名**：如 `oaid=`、`trans_info=`
- **最后追加 APP_KEY**：整个32位，不只是前16位

## 十一、PC Launcher 扫码登录完整链路（enter.js PCLauncherApp 状态机）

### 11.1 概览：扫码而非直连

**核心发现**：APP 端登录 **不是** 直接拿 SDK token 拼 URL 进游戏。真实流程是：

```
APP 扫码 PC 屏幕上的二维码 → APP 发送 sessionId + 登录凭证给服务端
→ PC 轮询检测扫描成功 → 服务端返回游戏入口参数 → PC 跳转进入游戏
```

`enter.js` 内置了一个完整的 **PCLauncherApp 状态机**，当 URL 包含 `genCode=true` 时激活。

**入口判断**（`bodyOnLoad()` enter.js:6019）：
```javascript
function bodyOnLoad() {
    0 <= window.location.href.indexOf("genCode=true")
        ? (s_pcLauncher = new PCLauncherApp).init()   // ← 扫码模式
        : window.cc ? ...s_x5webApp.init()             // ← 正常游戏模式
}
```

**实际入口 URL**：`https://dldl.50pk.com/login.php?genCode=true&lid=85`

### 11.2 PCLauncherApp 状态机（enter.js:5428-5562）

| 状态 | 常量 | 说明 |
|------|------|------|
| State_Empty | 初始 | 等待启动 |
| State_LoadQRCode | 已加载 qrcode.js | QR 库就绪 |
| State_LoadMD5 | 已加载 md5.js | MD5 库就绪 |
| State_GetId | 请求中 | 正在获取会话 ID |
| State_WaitData | 轮询中 | 每 1 秒轮询是否已扫码 |

为绕开真实扫码流程（需真机 APP），proxy.js 做了以下适配：

**c) 修改 enter.js 中的请求地址**（proxy.js:955-957）：

**d) `/api/app-login`** — 跳过扫码直接生成游戏入口 URL：
```
① 调 SDK /sdk/login/ 验证账号密码（拿 APP token、uid）

④ account.html 的 buildAppLoginUrl 直接用这些参数拼 URL
```

### 11.7 关键参数对照：SDK vs 游戏入口

| 参数 | SDK 登录 (`/sdk/login/`) | 游戏入口 (`/pc/getCodeInfo` 响应) |
|------|---------------------------|-----------------------------------|
| **gid** | `1002997`（游戏标识） | `1003279`（PC Launcher 入口实例） |
| **pid** | `1`（渠道） | `46`（入口渠道） |
| **token** | APP SDK token（短） | H5 token（长 BASE64） |
| **sign** | SignV3 客户端可计算 | **服务端生成**（H5 密钥，客户端不可计算） |
| **appVer** | `1.0.0` | `134` / `136` |
| **密钥体系** | APP_KEY | H5 signKey（服务端） |

> **结论**：`/sdk/login/` 和游戏入口是完全独立的两套参数体系。SDK token 只能证明"我是合法用户"，游戏入口参数（gid/pid/token/sign）由服务端 `/pc/getCodeInfo` 下发。客户端无法自己拼出有效的 sign。
